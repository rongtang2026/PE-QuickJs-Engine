0. 这一版是什么

作者唯一一个带 r- 前缀的发布，按他自己 README 的定义，这才是"正式版"。它也是三版里改动最剧烈的一版：

Vulkan无 → 有（65 个 vk* 函数）
防改 Qz7无 → 有
debuggabletrue → 关闭
dex6 个 → 1 个

时间点值得记一笔：删掉 Lua 发生在 11-01，而宣传视频也是 11-01 发的，视频简介写的是"比原先 PE 兼容模组性更上一层楼"。

#结论
1基底仍是 1.0（∩1.0=130 / ∩0.7.3=96，只属 0.7.3 的文件 0 个）
2Lua 运行时在这一版被整体删除，LuaJIT 与 FunkinLua.hx 同时消失

用户侧后果：从 1.0 升级到本版，签名不一致，必须卸载重装，存档与应用数据一并丢失。
