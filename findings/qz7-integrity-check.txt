# Qz7 —— APK 完整性/结构校验摘录

类: DingLing/pe/QuickJs/Engine/Qz7 (Java 侧探针)
判定逻辑在 Haxe 侧: backend/Qz7r.hx (字段 k/_f/_v/_w/_c/_m/_z, boot, scriptsAllowed)

## 方法一览
  .method public constructor <init>()V
  .method public static a(I)I
  .method public static b()I
  .method public static c()I
  .method public static d()I
  .method private static okRoot(Ljava/lang/String;)Z
  .method private static okSo(Ljava/lang/String;)Z
  .method private static v()[B

## 探针语义(按字节码逐方法确认)

v()                        取签名证书字节做 SHA-256，返回 byte[32]；静态字段 c 缓存
a(int i)                   从 byte[32] 取第 i 个 4 字节大端整数，i∈0..7
b()                        返回签名者数量(SigningInfo.hasMultipleSigners / getApkContentsSigners)
c()                        (ApplicationInfo.flags & 0x2) != 0 -> debuggable 标志
d()                        遍历 getPackageCodePath() 的 ZIP 条目做结构白名单检查

## 白名单实际内容

okRoot(name) 仅允许:
  AndroidManifest.xml
  resources.arsc
  DebugProbesKt.bin

okSo(path) 仅允许:
  libApplicationMain.so
  libc++_shared.so
  liblime.so
  libvlc.so

## 备注

- 不做逐条目哈希；比对期望值为 .so 内编译常量，非字符串。
- 本包 debuggable=true，c() 必然返回 1。
- 失败文案: This copy of the game was modified or re-signed.
